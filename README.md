# WokenPlan 3D

Web estática de impresión 3D preparada para GitHub Pages.

## Archivos
- `index.html` — página principal
- `style.css` — diseño responsive
- `script.js` — catálogo y botones de WhatsApp

## Publicarla en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube estos tres archivos a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)` y guarda.

Los botones de contacto ya apuntan a WhatsApp: **639 062 725**.

### Catálogo
Los tres productos iniciales son plantillas. Sustituye los nombres, precios, descripciones e imágenes en `script.js` cuando tengas el catálogo definitivo.
